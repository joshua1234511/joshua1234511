### Research

I'm doing a **PhD in Management at [IIM Sambalpur](https://www.iimsambalpur.ac.in)** (Working Professionals, from July 2026). My thesis is on a human-centred governance framework for AI-assisted decisions in organisations, built around **Empathy, Trust and Accountability (ETA)**.

### Open source

- **[ai_empathy](https://www.drupal.org/project/ai_empathy)**: a Drupal module that tests how empathetically AI models respond in real decisions. It includes governance policies (EU AI Act, OECD, NIST, India's AI Governance Guidelines and DPDP Act), a tool for AI agents, and ECA integration. You can try it as a [free empathy assessment](https://www.fernandesjoshua.com/empathy-assessment).
- **[ai-empathy-benchmark](https://github.com/joshua1234511/ai-empathy-benchmark)** and **[ai-empathy-eval](https://github.com/joshua1234511/ai-empathy-eval)**: code and datasets behind the research.
- **Drupal:** maintainer of 16+ projects, with core patches, security credits and documentation. I'm on [drupal.org](https://www.drupal.org/u/joshua1234511).
